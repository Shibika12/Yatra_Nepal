### Authentication APIs ###

# Register User
POST http://localhost:3002/api/auth/register
Content-Type: application/json

{
    "name": "Test User",
    "email": "test@example.com",
    "password": "test1234",
    "phone_number": "1234567890",
    "nationality": "Nepal",
    "user_type": "tourist"  // or "guide"
}

# Login
POST http://localhost:3002/api/auth/login
Content-Type: application/json

{
    "email": "test@example.com",
    "password": "test1234"
}

# Upload Guide Documents
POST http://localhost:3002/api/auth/upload-documents
Authorization: Bearer {{token}}
Content-Type: multipart/form-data

citizenship: [File]
license: [File]

### Blog APIs ###

# Create Blog
POST http://localhost:3002/api/blogs
Authorization: Bearer {{token}}
Content-Type: multipart/form-data

content: "This is a test blog"
images: [File1, File2]

# Get All Blogs
GET http://localhost:3002/api/blogs
Authorization: Bearer {{token}}

# Like/Unlike Blog
POST http://localhost:3002/api/blogs/{{blogId}}/like
Authorization: Bearer {{token}}

# Delete Blog
DELETE http://localhost:3002/api/blogs/{{blogId}}
Authorization: Bearer {{token}}

### Guide APIs ###

GET http://localhost:3002/api/guides/guide-profile/{{userId}}
Authorization: Bearer {{token}}

PUT http://localhost:3002/api/guides/guide-profile/{{userId}}

### Variables to Replace ###
{{token}} - JWT token received after login
{{admin_token}} - JWT token received after admin login
{{userId}} - User ID
{{guideId}} - Guide ID
{{blogId}} - Blog ID
{{notificationId}} - Notification ID

### Notes ###
1. For file uploads, use form-data
2. Keep Authorization header format as "Bearer {token}"
3. Replace all {{variables}} with actual values
4. For admin routes, use admin login credentials
5. All timestamps should be in YYYY-MM-DD format
